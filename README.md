> 把零散想法压制成 AI 可执行的项目规范：四套模板定版式、R/P0–P2 四道工序成型、P3 进入任务循环

- [提示词生产线](ai-prompt-line) — 喂一个想法输出一整套项目规范，含需求/技术选型/AGENTS/验证分册四套模板与四工序质检清单

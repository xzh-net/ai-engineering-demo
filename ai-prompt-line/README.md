# ai-prompt-line

> 把零散想法变成需求文档，完成技术选型，再通过验证确认方案可行。
> 一条从**需求 → 选型 → 验证 → 复盘 → 门禁**的提示词生产线；P1–P6 是执行验证、复盘、门禁与后续开发的载体。

---

## 你是使用者

从 [`使用说明/README.md`](使用说明/README.md) 开始。那里是唯一入口：主线速查、每步用哪个提示词、产物落哪、怎么验收。

- 提示词：[`使用说明/prompts/`](使用说明/prompts/)（R / P0 / P1 / P2 / P3 / P4 / P5 / P6）
- 模板、样例与检查器：[`使用说明/资产/`](使用说明/资产/)（含黄金样例 [`样例_完整项目`](使用说明/资产/样例_完整项目/)）
- 排障：[`使用说明/常见问题.md`](使用说明/常见问题.md)

## 你是修改者

读两份：

1. [`维护/项目介绍.md`](维护/项目介绍.md)——设计原理、文件地图、改哪里、版本路线
2. [`维护/修改记录.md`](维护/修改记录.md)——改动过程与旧结论推翻关系

改完跑 [`维护/审计清单.md`](维护/审计清单.md)。根目录的 [`AGENTS.md`](AGENTS.md) 会自动加载，是修改纪律的硬约束。

---

## 主线

```text
想法 → R 需求 → P0 选型 → 你拍板 → P1 AGENTS+状态机 → P2 验证分册 → P3 验证任务 → P4 验证报告 → 选型结论
                                                                          ↳ P5 复盘 → 规则候选 → 你确认 → 写回规则
开工前/收尾 ↳ P6 门禁 → 四项机检 → 全绿后按 §1.6 下一步续跑
```

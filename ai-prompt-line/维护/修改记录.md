# 修改记录（面向修改者，使用者不需要读）

> 本文件只记**改动过程**：何时改了什么、为什么、影响哪些引用、旧结论何时被推翻。
> 使用者的操作指导一律在 `使用说明/`；本文件只属维护侧，使用者侧不引用它。
> 纪律：正文每句都要能回答"读者据此能多做什么/少做什么"——答不出的放这里。
> **职责边界**：`git log` 记"改了什么"（文件、行数、提交号）；本文件只记 `git log` 表达不了的——**为什么改、旧结论何时被谁推翻、影响了哪些引用、快照在哪**。同一件事两边都提时，本文件不复述 diff，只写 git 里看不到的部分。
> **快照锚点**：本仓库历史完整，任何时刻的状态用 `git show <hash>` 取，不依赖外部备份（曾有的桌面备份 `C:\Users\admin\Desktop\ai-prompt-line` 已于 2026-11-06 后被移除，全盘无同名目录；其内容 = 重命名前状态 = `a63d989`，已由 git 覆盖，无信息损失）。

**条目格式（新增条目照抄字段，不缺项）**：

```markdown
### 日期 · 一句话摘要
- 改了什么：（对象 + 关键动作，不贴 diff）
- 为什么：（动机/触发问题）
- 影响的引用：（被同步修改的文件与章节；无则写"无"）
- 旧结论推翻关系：（推翻/被推翻哪条，无则写"无"）
- 快照/审计：（对应 commit hash 或备份路径；审计结论）
```

# P4 · 选型验证报告提示词（复制即用）

> 对应模板：`../资产/模板_选型验证报告.md`
> 用法：某阶段或全部验证项跑完后，在**目标项目根**会话中，把下方整段复制，替换 `{阶段范围}` 与 `{报告日期}`。
> 验收：证据表行数 = 分册验证项总数、每个"通过"都有原始数据、判定按阈值、结论回写方案 §X 与 AGENTS §1.6。

```text
按 AGENTS.md 生成选型验证报告：{阶段范围：如 阶段 0–1 全部验证项 / 全部验证项}（报告日期：{YYYY-MM-DD}）
输入：
- 报告模板：{模板_选型验证报告.md 的内容（整份粘贴，不要只给路径）}
- 基线：{AGENTS.md 路径（取 §1.2 判定条件、§1.6 任务表与证据路径）+ 技术选型方案路径（取 §X 验证路线阈值）}
- 过程档案：docs/验证记录/ 目录下的全部验证记录

要求：
1. 若本会话是新会话，先按 §1.7 输出"续接四问"，我确认后再动手；非新会话也先报 §1.6 中相关任务的状态；
2. 先拉齐验证项全集：以激活分册"本阶段验证项清单"为准，逐项取 V-NN 编号与方案 §X 出处，不得漏项、不得自增项；
   若 AGENTS §1.6 与分册项数不一致：仍以分册为准出报告，差异逐条写入缺口清单，不擅自增删验证项；
3. 逐项找原始数据：到 docs/验证记录/ 对应记录中取环境、样本量、统计口径、原始数据路径、实测值；
   找不到原始数据的项，判定只能写"待补测"，**禁止**用对话印象或推算值补成"通过"；
4. 判定只用四值：通过 / 不通过 / 待补测 / 不适用；按方案阈值逐项比较，阈值逐字带出处、不得修改；
   不通过项写明启用哪个备选、谁拍板；未拍板的一项写入 §1.6 挂起表；
5. 总体结论三选一：可交付 / 走备选 / 未收口，并与判定计数自洽；
6. 按模板生成报告，保存为 docs/技术选型/{YYYY-MM-DD}_选型验证报告.md；状态先写"待验收"，等我确认后再改"已验收"；
7. 收口回写：方案 §X 每阶段表下追加"验证结论：{计数}（报告：{路径}）"；AGENTS §1.6 更新相关任务的状态/证据/日期；
   核对 §1.2 判定条件，全满足则宣告并执行切换清单，未满足写明尚缺哪几条；
8. 自查并按模板"生成后自查"逐项报告（实测点数，不看自称）：分册项数 = 证据表行数、每个通过有原始数据、阈值带出处、结论与计数自洽、回写已完成；
9. 输出缺口清单：待补测项、缺失证据、未拍板事项、环境不可复现项，各给下一步建议；报告状态未"已验收"前，结论不得当作基线。
```

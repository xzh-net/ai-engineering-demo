# P5 · 复盘与规则候选提示词（复制即用）

> 对应模板：`../资产/模板_学习记录.md`
> 用法：阶段收口或发生重大纠偏后，在**目标项目根**会话中，把下方整段复制，替换 `{复盘范围}`。
> 验收：候选有证据、根因单层、条文可执行、工具环零改写、未确认的不进 AGENTS。

```text
按 AGENTS.md 执行复盘：{复盘范围：如 阶段 1 收口 / V-02 返工纠偏 / 本次会话全部纠偏}
输入：
- 学习记录模板：{模板_学习记录.md 的内容（整份粘贴，不要只给路径）}
- 基线：{AGENTS.md 路径（取 §1.2、§1.6、§1.8、§十）+ 选型验证报告路径 + 激活分册路径}
- 事实来源：docs/验证记录/、docs/开发记录/、docs/问题记录/、本次会话中用户对我的纠偏与返工

要求：
1. 若本会话是新会话，先按 §1.7 输出"续接四问"，我确认后再动手；非新会话也先报 §1.6 中相关任务的状态；
2. 只复盘已发生事件：每条案例记忆必须有证据路径（记录文件/日志/截图）；无证据的"感觉"不进学习记录；
3. 规则候选每条：现象、根因层（只定一层：提示词/模板/质检/使用说明/AGENTS/执行）、建议条文（可直接粘贴的祈使句）、环（项目/工具）；
   条文禁止写日期、实例名、硬编码章节号；
4. 环判定：项目环 → 拟写入 AGENTS 具体章节，等我确认后才改；工具环（跨项目复用的模板/提示词/质检缺陷）只在学习记录里记候选，
   **不得修改工具仓任何文件**；
5. 先查 §6 已否决清单：同一现象无新证据不得重提；同一现象第三次出现，必须升级为工具环候选；并在 §6 写"本次复核"结论（无否决项写"无"）；
6. 按模板生成 docs/学习记录/{YYYY-MM-DD}_学习记录.md，状态写"复盘进行中"；候选状态初始一律"候选"，只有我能改"已确认"；
   候选ID 按项目全局连续递增：建记录前先查历史学习记录的最大 L 编号，`L-NN` 不复用、不跨文件重号（含已否决条目）；
7. 我确认后：项目环写入 AGENTS 并在 §1.8 留痕，工具环标"已确认（待回灌）"；**当场**在 §5 填验证方式与"未验证"，
   并把学习记录状态改"已归档"、按模板自查逐项重跑；验证通过才标"已生效"，未验证前不得标"已生效"、不得宣称"已学习"；
8. 汇报：案例 {N} 条 / 候选 {M} 条（项目环 {X}、工具环 {Y}）/ 已否决复用 {Z} 条 / 需要我现在拍板的事项；
9. 按模板"生成后自查"逐项报告（实测不看自称）：证据路径齐、根因单层、条文可执行、工具环零改写、状态一致、候选ID 无重号、§6 有本次复核。
```

# P3 · 每个任务的固定提示词（复制即用）

> 用法：在**目标项目根**会话中，把下方整段复制，替换 `{任务描述}` 与 `{任务ID}`；验证任务与开发任务都用它。
> 验收：先过入口协议再分诊；收尾按 §十 八段汇报；"状态同步"逐项回答；§1.6 该任务已回写且证据含六要素。

```text
按 AGENTS.md 执行本任务：{任务描述}（任务ID：{V-01 / T-001}）
要求：
1. 若本会话是新会话，先按 §1.7 输出"续接四问"，我确认后再动手；非新会话也先报该任务在 §1.6 中的当前状态；
2. 按 §三分诊并列计划再动手；
3. 完成后严格按 §十 八段汇报，"状态同步"段必须逐项回答（含 §1.2 判定条件核对：尚缺哪几条）；
4. 收尾更新 §1.6：该任务ID的状态、证据/记录路径、更新日期，以及"下一步"；证据/记录须含六要素（环境/样本量口径/原始数据路径/实测值/阈值出处/判定），缺原始数据不得置"已完成"；完整性四查必须过；
5. 你发现规范缺口或收到我的纠偏时，按 §1.8 先记规则候选（L-NN，带证据路径与根因层），经我确认后才改规则；我对你的任何纠偏都会要求"把这条写进 AGENTS"。
```

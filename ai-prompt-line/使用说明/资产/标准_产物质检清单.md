# QC · 产物质检清单（送检用，随产物流动）

> **用法（送检姿势）**：把**产出物全文 + 工序名（R / P0 / P1 / P2 / P4）+ 所用模板**（内容或文件名）发给任意 AI 会话，让它按本清单逐项过检，输出**三段式报告：过检清单（打勾表）/ 不过项（行号 + 病层）/ 修法建议（指到哪一层改）**。
> **定位**：本文件是**质检标准（帮助文档）**，不是 AGENTS 规则——送检会话的工作目录在**被检项目**里，ai-prompt-line 的 AGENTS 不会自动加载，所以标准必须整份可粘贴、随产出物流动。
> **范围**：本文件只含送检用的过检表（§一–§五）；病层定位与回仓审计属修改者内容，不在本文件内。
> **修复归属**：根因在被检项目 → 按被检项目的 AGENTS 修；根因在 ai-prompt-line 的提示词/模板 → 交回 ai-prompt-line 维护者。**动手改文件一律经用户确认，审计会话只诊断开方。**

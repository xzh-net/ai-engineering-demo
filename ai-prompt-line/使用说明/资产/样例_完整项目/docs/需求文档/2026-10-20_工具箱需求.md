# 工具箱需求文档

- 日期：2026-10-20
- 状态：已确认

## 1. 目标

做一个本地命令行工具箱，启动快、占用低，用于日常文件整理与批量重命名。

## 2. 范围

| 能力 | 说明 | 优先级 |
|---|---|---|
| 冷启动 | 启动到可接受命令 ≤3 秒 | 必须 |
| 内存占用 | 常驻峰值 ≤800 MB | 必须 |
| 双屏适配 | 窗口位置在双屏下不越界 | 必须 |
| 批量重命名 | 支持通配符与预览 | 应该 |

## 3. 边界

- 不联网、不上传数据、不读取用户隐私目录。
- 只支持 Windows 10 及以上。

## 4. 验收标准

1. 三项必须能力均有实测数据与判定；
2. 无第三方运行时依赖；
3. 启动与内存数据可复现（原始数据留档）。

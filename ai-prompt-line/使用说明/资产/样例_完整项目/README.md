# demo-toolbox · 演示工具箱

> 本目录是 ai-prompt-line 的**黄金样例**：一条完整跑通 R → P0 → P1 → P2 → P3 → P4 → P5 → P6 的目标项目。
> 用途：作为门禁检查器的回归基准（应四项全绿、退出码 0），同时演示各产物的正确形态。

## 怎么用

```text
python ../../工具_门禁检查器.py --root .
```

或在本仓任意位置：

```text
python 使用说明/资产/工具_门禁检查器.py --selftest
```

## 验收状态

- 三项验证：2 项通过、1 项不适用，证据表 3 行与分册 3 项一致
- 任务表：3 项已完成、1 项挂起（等待配置格式拍板）
- 门禁：四项全绿，退出码 0

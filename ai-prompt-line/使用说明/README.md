# 使用说明 · 需求 → 选型 → 验证

> **这是使用者的唯一入口。** 修改者内容不在本目录。
> 主线：把零散想法变成需求文档，完成技术选型，再通过验证确认方案可行（R → P0 → 拍板 → P1 → P2 → P3 → P4 → 按需 P5 → P6 门禁）。

---

## 1. 你的边界（先读）

| 归属 | 范围 | 你能做什么 |
|---|---|---|
| **你的地盘** | 你自选的**目标项目**文件夹（任意位置） | 任意创建、修改生成物；按项目 AGENTS 的项目环章节更新规则 |
| **只读区（维护者内容）** | 本工具仓全部文件：`使用说明/`（含本文件、操作说明、流程与机制、常见问题、资产）与 `维护/`、根 `AGENTS.md` | **只读**：读、复制、粘贴到会话、执行；发现问题走 §3 送检反馈，**不要就地改** |

一句话：**能改的只有你的目标项目；工具仓一个文件都不要改。** 模板在目标项目里的复制件同样**只读**（要改回工具仓改，只影响新项目）。

---

## 2. 怎么用（三步）

1. 按 [`操作说明.md`](操作说明.md) 的 **S0** 建项并复制输入文件（6 模板 + 质检清单 + 检查器 → 项目内 `docs/模板/`）；
2. 按 **S1–S9** 逐段复制提示词到会话执行，每步照"产出 / 验收"自查——八段提示词全在操作说明内；
3. 机制不明白看 [`流程与机制.md`](流程与机制.md)；出问题翻 [`常见问题.md`](常见问题.md)。

**复制与冻结**：模板等输入必须复制进目标项目（复制件=该项目唯一输入源，只读、随项目冻结，工具仓后续调整不影响已建项目）；提示词只复制到**会话**。详见操作说明 §0。

---

## 3. 送检

任一步产出物都可送检：读项目内 `docs/模板/标准_产物质检清单.md`，把**产出物全文 + 工序名（R/P0/P1/P2/P4/P5/P6）+ 所用模板**发给任意 AI 会话，按对应工序过检表逐项核。

- 输出三段式报告：过检清单 / 不过项 + 病层 / 修法建议。
- 根因在被检项目 → 按被检项目的 AGENTS 修；根因在工具仓 → 反馈给工具仓维护者。
- **你手动送检是唯一触发器，不设强制。**
